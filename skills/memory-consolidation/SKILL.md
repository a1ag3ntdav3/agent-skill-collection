# Memory Consolidation

Use this skill when completing complex multi-step tasks or debugging sessions to compact logs and save reusable patterns.

## Instructions
1. **Analyze logs**: Review recent execution logs, command history, and errors.
2. **Extract lessons**: Identify successful resolution paths, architectural decisions, and key lessons.
3. **Check duplicates**: Review existing LLM Wiki files to check for overlapping content.
4. **Consolidate**: Write or update specific wiki markdown pages with the distilled semantic rules.
5. **Prune context**: Archive or delete verbose intermediate files to maintain minimal context length.
