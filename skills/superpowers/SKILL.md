# Superpowers

Use this skill when coordinating multi-agent engineering workflows or executing complex development cycles.

## Instructions
1. **Roles**: Assign specialized subagent roles (e.g. Architect, Developer, Reviewer).
2. **Scaffolding**: Define stable interfaces and directory layouts first.
3. **Execution**: Follow strict Test-Driven Development (TDD) loops.
4. **Guardrails**: Require developer check-offs on git updates or commands.
5. **Quality Review**: Validate code structure, performance, and formatting.
