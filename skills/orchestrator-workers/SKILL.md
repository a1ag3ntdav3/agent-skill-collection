# Orchestrator-Workers

Use this skill to implement the Orchestrator-Workers pattern, delegating complex tasks to specialized workers and synthesizing their outputs into a final consolidated deliverable.

## Instructions
1. **Decompose**: Split a complex, multi-faceted task into distinct, independent subtasks.
2. **Delegate**: Assign each subtask to a specialized worker agent with a precise system prompt and workspace.
3. **Execute**: Run worker tasks in parallel or sequence, monitoring for failures.
4. **Synthesize**: Gather the outputs from all worker agents, review them, and merge them into a single, cohesive final solution.
