# Diagnose & Fix

Use this skill when resolving exceptions, build failures, or logic errors.

## Instructions
1. **Information**: Capture stack traces, compilation outputs, and logs.
2. **Hypothesis**: Formulate hypotheses about the root cause without guessing.
3. **Regression Test**: Write a test that reproduces the bug, confirming it fails.
4. **Minimal Fix**: Modify the codebase minimally to resolve the failing test.
5. **Verification**: Run the full test suite to verify no regressions were introduced.
