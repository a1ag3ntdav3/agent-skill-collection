# Goal-Driven Execution

Use this skill when running long-running processes or background loops autonomously.

## Instructions
1. **Planning**: Decompose the goal into sequential subtasks.
2. **Looped Iteration**: Plan, execute commands/tools, evaluate the output, and adjust.
3. **Pacing**: Log progress checkpoints and notify the user periodically.
4. **Self-Correction**: Read error logs, debug, and rewrite code autonomously on failure.
5. **Completion**: Stop only when the high-level objective is fully validated.
