# Multi-Agent Debate

Use this skill when resolving complex problems, conducting audits, or validating high-stakes decisions.

## Instructions
1. **Initialize Personas**: Assign distinct, opposing viewpoints or specialized roles to participant subagents (e.g., Maker vs. Checker, Optimist vs. Skeptic).
2. **Debate Iteration**: 
   - Prompt the first agent to generate an initial proposal.
   - Instruct the second agent to review and critique it, suggesting improvements.
   - Run up to 2-3 turns of structured critique and response.
3. **Consensus & Synthesis**:
   - Run a moderator or judge agent to review the debate history.
   - Synthesize the final conclusion, highlighting resolved conflicts and final recommendations.
