# Prompt Engineering

Use this skill when designing prompts for system instructions, few-shot examples, or structured output schemas.

## Instructions
1. Specify clear **System Instructions** to pre-condition the model's behavior and style.
2. Use **Few-Shot Examples** to guide the output format (e.g. JSON extraction).
3. Enforce **Chain of Thought (CoT)** by requesting the model to think step-by-step before answering.
4. Set explicit output format requirements (e.g. Markdown or JSON schemas).
5. Track and version control prompt changes.
