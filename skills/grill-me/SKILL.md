# Grill Me

Use this skill when you need to align on requirements, architecture, or edge cases before writing code.

## Instructions
1. Act as a Socratic interviewer; do NOT write any code during the grilling phase.
2. Ask 3-5 highly specific, critical questions about constraints, design choices, and dependencies.
3. Walk through decision tree branches to resolve ambiguities.
4. Synthesize responses and wait for explicit sign-off from the user before starting implementation.
