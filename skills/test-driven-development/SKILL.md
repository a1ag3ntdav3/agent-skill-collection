# Test-Driven Development (TDD)

Use this skill when implementing new features or adding code blocks to prevent bugs.

## Instructions
1. **Red**: Write a failing test outlining the expected behavior. Run it and confirm failure.
2. **Green**: Write the minimal code implementation to pass the test. Run it and confirm success.
3. **Refactor**: Clean up the code structure and verify the tests stay green.
4. **Vertical Slice**: Add features behavior-by-behavior, rather than in one massive push.
