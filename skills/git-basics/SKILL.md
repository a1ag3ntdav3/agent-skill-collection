# Git Basics

Use this skill when you need to initialize a repository, stage changes, commit updates, or check git status.

## Instructions
1. Run `git status` to see untracked/modified files.
2. Stage files using `git add <file>` or `git add .` to prepare for commit.
3. Commit staged changes with a descriptive message: `git commit -m "<message>"`.
4. Verify by running `git log --oneline` to ensure commits are recorded.
